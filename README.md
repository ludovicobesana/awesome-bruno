# Awesome Bruno [![Awesome](https://awesome.re/badge-flat2.svg)](https://awesome.re)

<img src="bruno-logo.svg" align="right" width="100" alt="Bruno logo">

> A curated list of tools, learning resources, integrations, and real-world collections for [Bruno](https://www.usebruno.com/), the Git-friendly API client.

Bruno users, API developers, QA engineers, and automation teams can use this list to find practical resources for exploring APIs, keeping collections in version control, and running repeatable API tests locally or in CI.

## CLI & CI/CD

- [Bruno CLI](https://docs.usebruno.com/bru-cli/overview) - Run collections, folders, and requests from the command line.
- [Docker Integration](https://docs.usebruno.com/bru-cli/docker) - Run the Bruno CLI in a Docker container.
- [GitHub Actions](https://docs.usebruno.com/bru-cli/github-actions/overview) - Official guide to running collections in GitHub Actions.
- [Jenkins CI Integration](https://docs.usebruno.com/bru-cli/jenkins) - Run Bruno collections from Jenkins.
- [Secret Managers](https://docs.usebruno.com/bru-cli/secret-managers) - Configure CLI runs to obtain secrets from supported secret managers.
- [usebruno/bruno-cli-action](https://github.com/usebruno/bruno-cli-action) - Official GitHub Action for running Bruno CLI commands, including JUnit reporting.
